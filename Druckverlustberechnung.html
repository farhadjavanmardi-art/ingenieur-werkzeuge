Berechnungsgrundlagen

Das Tool berechnet den Druckverlust basierend auf der erweiterten Bernoulli-Gleichung.

1. Gesamtdruckverlust

$$ \Delta P_{ges} = \sum (\Delta P_{Rohr} + \Delta P_{Armatur} + \Delta P_{Höhe}) $$

2. Rohrreibung (Darcy-Weisbach)

$$ \Delta P_{Rohr} = \lambda \cdot \frac{L}{d} \cdot \frac{\rho}{2} v^2 $$

3. Einzelverluste (Armaturen)

$$ \Delta P_{Armatur} = \zeta \cdot \frac{\rho}{2} v^2 $$

K-Wert (\( \zeta \)) ist DN-abhängig.

Hilfe & Anleitung

Verwendung:

  1. Wählen Sie Fluid und Durchfluss.
  2. Fügen Sie Rohrabschnitte hinzu (Länge, DN, Höhe).
  3. Fügen Sie Armaturen hinzu. Die Ergebnisse werden in Echtzeit berechnet.
  4. Das Diagramm zeigt den Druckverlustverlauf: Schräge Linien sind Rohre, vertikale Sprünge sind Armaturen.
  5. Exportieren Sie die Ergebnisse nach Excel.

Info: Druckverlustberechnung (Hydraulik)

Anwendung dieser Seite

Dieses Tool berechnet den Gesamtdruckverlust in einer Rohrleitung (Rohrreibung + lokale Verluste durch Armaturen + Höhenunterschied). Die Ausgabe erfolgt in bar und Pa, und das Druckverlustprofil wird entlang der Strecke im Diagramm dargestellt.

Nutzung

  1. Stellen Sie Medium/Fluid und Durchfluss (Q) ein.
  2. Geben Sie für jeden Abschnitt (Abschnitt) DN, Länge (L) und Höhendifferenz (Δz) ein.
  3. Fügen Sie Armaturen/Fittings für jeden Abschnitt hinzu.
  4. Die Ergebnisse werden in Echtzeit aktualisiert: Gesamtdruckverlust, Verlust pro Abschnitt, Geschwindigkeit, Re und λ.

Formeln und Berechnungslogik (entspricht dem Code dieser Datei)

Durchflussumrechnung:
Wenn Einheit m³/h: \(Q = Q_{raw}/3600\)
Wenn L/min: \(Q = Q_{raw}/60000\)
Wenn L/s: \(Q = Q_{raw}/1000\)
Fläche und Geschwindigkeit:
\(A = \pi \left(\frac{d}2\right)^2\)
\(v = \frac{Q}{A}\)
Reynolds-Zahl:
Im Code wird die Viskosität von mPa·s in Pa·s umgerechnet: \(\mu = \mu_{mPa\cdot s}/1000\)
\(Re = \frac{\rho v d}{\mu}\)
Reibungsbeiwert (λ):
Für laminare Strömung: \(\lambda = \frac{64}{Re}\)
Für Re>2300 (turbulent/Übergang) wird im Code die explizite Formel verwendet:
\(\lambda = \frac{0.25}{\left[\log_{10}\left(\frac{\varepsilon}{3.7d} + \frac{5.74}{Re^{0.9}}\right)\right]^2}\)
Gelöst wird Colebrook-White iterativ: \(\frac{1}{\sqrt{\lambda}} = -2\log_{10}\left(\frac{\varepsilon}{3.7d} + \frac{2.51}{Re\sqrt{\lambda}}\right)\)
Die Formel darüber ist die Näherung nach Swamee-Jain; sie dient nur noch als Startwert. \(\varepsilon\) wird je Abschnitt eingegeben - Werkstoff und Zustand entscheiden, nicht das Werkzeug.
Zwischen Re 2300 und 4000 wird mit der turbulenten Formel gerechnet. Das ist üblich, aber der Übergangsbereich ist von Natur aus unsicher; die Zeile "Regime" sagt es an.
Dynamischer Druck:
\(p_{dyn} = \frac{1}{2}\rho v^2\)
Druckverlust pro Abschnitt:
Rohrreibung (Darcy-Weisbach): \(\Delta p_{pipe} = \lambda \frac{L}{d} p_{dyn}\)
Lokale Verluste (Armaturen): \(\Delta p_{fit} = \left(\sum \zeta\right) p_{dyn}\)
Verlust/Gewinn durch Höhe: \(\Delta p_{geo} = \rho g \Delta z\) mit \(g=9.81\)
\(\Delta p_{sec} = \Delta p_{pipe} + \Delta p_{fit} + \Delta p_{geo}\)
Einheitenumrechnung:
\(\Delta p_{bar} = \Delta p_{Pa} / 100000\)
ζ für Armaturen:
Der Code enthält eine interne Datenbank (fittingsDB). Für einige Artikel ist ζ fest, für andere ist es DN-abhängig und der nächstgelegene DN wird aus der Tabelle ausgewählt.

Diese Seite ist ein Ingenieurtool, kein Normdokument. Wenn Sie es an Normen/Projektbedingungen anpassen möchten, müssen Sie die Datenbank für Rauheit/Armaturen/Strömungsbeziehungen entsprechend den tatsächlichen Spezifikationen konfigurieren.
