Hydrocyclone Calc - Hilfe

This tool mirrors the Excel sizing logic (Vorlage_Hydrozyklone.xlsx): target separation defines a theoretical cyclone size, then the chosen DN is evaluated with the same correction factors and capacity model.

1. Separation Target → d50,application

f = a · ln(Rr,w) + b    (a = -3.16721, b = 15.12624)
d50,application = dw · f

2. Correction Factors (C1, C2, C3)

C1 = ((53 - c) / 53)-1.43
C2 = 3.27 · (100 · dp)-0.28
C3 = (1.65 / (GS - GL))0.5

C_total = C1 · C2 · C3

3. Base Cut & Theoretical Diameter

d50,base = d50,application / C_total
D_theor = 10 · (d50,base / 2.84)1/0.66

4. Chosen DN Performance

d50,DN,base = 2.84 · (DN/10)0.66
d50,DN,application = d50,DN,base · C_total

5. Geometry Rules

  • Ae = 0.05 · D², le = √Ae
  • l (Tauchrohr) = 0.35 · D
  • H (Zylinder) = D
  • Du (Unterlauf) = 0.25 · D (default)
  • h (Konus) = (D - Du) / (2 · sin(fi))
  • L = le + H + h

6. Capacity Model (Vdot/Zyklon)

Empirical fit from the Excel helper table (ABA 2025):

a(D) = αD³ + βD² + γD + δ
Vdot/Zyklon = a(D) · dpb

α=1.802e-05, β=-0.0089682, γ=1.70931167, δ=-90.0575, b=0.52075

2. Correction Factors

To obtain the actual application cut point, three correction factors are applied:

C1 (Solid Concentration): Corrections for hindered settling.

C1 = ((53 - c) / 53)-1.43
// c = Volumetric Solids %

C2 (Pressure Drop): Impact of pressure energy.

C2 = 3.27 × (100 × dp)-0.28
// dp = Pressure drop (bar)

C3 (Density Difference): Impact of specific gravity.

C3 = √ [ 1.65 / (Gs - Gl) ]
// Gs = Solid Density, Gl = Liquid Density

3. Actual Cut Point (d50_app)

d50_app = d50_base × C1 × C2 × C3

4. Geometry Rules

Geometric dimensions are derived from the cyclone diameter (D) based on high-efficiency standard ratios:

  • Inlet Area (Ae): 0.05 × D²
  • Vortex Finder (l): 0.35 × D
  • Cylinder Height (H): 1.0 × D
  • Cone Height (h): Derived from Cone Angle (θ):
    h = (D - Du) / (2 × sin(fi))
