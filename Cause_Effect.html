C&E Matrix Pro | Anwendung & Formeln

Anwendung dieser Seite:
Dieses Tool dient zum Erstellen und Verwalten einer C&E Matrix: Definieren von Ursachen (Cause) und Wirkungen (Effect) sowie der Logik dazwischen.
Nutzung:
  1. Fügen Sie mit den Buttons Ursache und Wirkung neue Elemente hinzu (oder wählen Sie eine Vorlage).
  2. Klicken Sie in der Tabelle auf die Zellen, um den Logik-Status zu ändern: X → A → T → R → (leer).
  3. Zum Testen aktivieren Sie Testen und klicken auf eine Ursachen-Zeile, um aktive Wirkungen hervorzuheben.
  4. Datenaustausch: Excel Import und Export.
Logik/Status (Code-Logik): 
States: ['', 'X', 'A', 'T', 'R']

X = TRIP (Auslösung)
A = ALARM
T = DELAY (Verzögerung)
R = RESET

Link-Key:
key = `${cause.id}-${eff.id}`
matrixData.links[key] = state
Datenstruktur (im File): 
matrixData = {
  causes: [{id, tag, desc}, ...],
  effects:[{id, tag, desc}, ...],
  links:  {'causeId-effectId': 'X|A|T|R', ...}
}
Hinweis Excel Import/Export:
Beim Export wird der Header der Effects-Spalte als TAG | DESC geschrieben. Beim Import werden Effects ab Spalte 4 gelesen und Links aus den Zellinhalten extrahiert.
