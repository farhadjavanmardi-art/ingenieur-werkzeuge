Brandschutz Master | Rules, Structure, Standards Mapping

What this tool is:
A professional, global fire protection framework that organizes typical building fire safety requirements into a structured checklist and produces a draft “Fire Safety Concept” document and quick 3D intent visuals.
What this tool is not:
Not a certified code checker. Not a substitute for local codes, approvals, or an authority having jurisdiction (AHJ). It refuses to “invent compliance”.
How the “standard packs” work:
  • EU (EN/DIN + ISO): Uses EN-style terminology (reaction/resistance, fire compartments, smoke control).
  • US (NFPA/IBC): Uses NFPA-style building systems framing (alarm, sprinklers, smoke control, egress planning).
  • UK (BS): Uses BS-style “fire strategy” approach (performance + risk-based).
  • Custom: You set the project-specific rule thresholds and notes.
This is a structural mapping so your team’s work is consistent, auditable, and review-ready.
Engine logic (transparent): 
Inputs:
  - Occupancy/use
  - Floors / height
  - Area / occupants
  - Compartment strategy
  - Alarm and suppression concepts
  - Risk/criticality

Derived flags:
  - High-rise flag: floors >= High-rise threshold
  - Special hazards: industrial / data center / underground (notes)
  - Open-plan flag: compartment = OPEN_PLAN

Output:
  - Checklist items grouped by category
  - Suggested document sections
  - 3D intent model (stacked floors) with markers
3D “smart pins & wires” reality check:
For CAD/BIM intelligence you still need BIM authoring or AutoCAD Electrical APIs. This tool provides clear geometry and tags so downstream tools can attach intelligence cleanly.
