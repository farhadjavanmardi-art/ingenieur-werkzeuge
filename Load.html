Load Master (Trafo / Motor / Heizung) | Anwendung & Formeln

Diese Seite wird zur Berechnung elektrischer Lasten verwendet: Transformatorauswahl, Motorstrom/-leistung und Heizungsauslegung. Die Ergebnisse werden direkt basierend auf den Formeln in diesem HTML berechnet.

Verwendung

  • Wählen Sie oben das Modul: Transformator, Motor & Antrieb oder Elektrische Heizung.
  • Geben Sie die Werte ein und klicken Sie auf Berechnen.
  • Die Ergebnisse (kVA, A, kW) werden in der Ergebnisbox angezeigt.

Formeln (Transformator)

P_active = P_inst * sim

S_req = (P_active / (pf * eff)) * (1 + res_pct/100)

I_sec = (S_selected * 1000) / (sqrt(3) * V_sec)

Utilization[%] = (S_req / S_selected) * 100

Kurzschluss an der Unterspannungsschiene

I_k" = I_n * 100 / u_k          (IEC 60909, Speisung nur aus dem Trafo)
i_p  = kappa * sqrt(2) * I_k"
kappa = 1,02 + 0,98 * e^(-3*R/X),  R/X = u_R / sqrt(u_k² - u_R²),  u_R = P_k / S_n

uk und Pk stehen auf dem Typenschild. Das vorgelagerte Netz wird weggelassen: seine Impedanz kaeme in Reihe dazu und wuerde den Strom kleiner machen. Ohne sie kommt also zu viel heraus - und beim Schaltvermoegen ist zu viel die sichere Richtung. Wer die Netzkurzschlussleistung des Versorgers hat, rechnet genauer; fuer die Geraeteauswahl liegt dieser Wert nie darunter.

Formeln (Motor)

P_elec = P_mech / eff

S = P_elec / pf

I (1-phase @230V) = (P_elec * 1000) / (V * pf)

I (3-phase) = (P_elec * 1000) / (sqrt(3) * V * pf)

I_DOL ≈ 7 * I
I_StarDelta ≈ 2.3 * I

Formeln (Heizung)

ΔT = T2 - T1

Q_kJ  = mass * cp * ΔT
Q_kWh = Q_kJ / 3600

P_kW = (Q_kWh / hours) * safetyFactor

I_3ph@400V ≈ (P_kW * 1000) / (sqrt(3) * 400)
I_1ph@230V ≈ (P_kW * 1000) / 230

Tastaturkürzel: Drücken Sie Esc, um die Hilfe zu schließen.
