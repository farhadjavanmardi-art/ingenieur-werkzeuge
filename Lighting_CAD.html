Lighting Calc - Hilfe

Ein Tool zur Berechnung der Beleuchtungsstärke (Lux) nach der Lumen-Methode inklusive 3D-Simulation der Leuchtenanordnung.

Anleitung

  • Geometrie: Geben Sie Länge (L), Breite (W) und Höhe (H) des Raumes ein. Definieren Sie die Höhe der Arbeitsebene (Workplane).
  • Anforderung: Wählen Sie den Raumtyp (z.B. Büro 500 Lux) nach DIN EN 12464.
  • Leuchte: Wählen Sie einen Leuchtentyp oder geben Sie Lumen/Watt manuell ein.
  • Reflexionsgrade: Decke, Wand und Boden gehen in den Betriebswirkungsgrad ein. Ein dunkler Raum braucht spürbar mehr Leuchten als ein heller.
  • Gleichmäßigkeit: Neben der mittleren Beleuchtungsstärke fordert EN 12464-1 immer eine Gleichmäßigkeit U0 = Emin/Emittel. Sie wird auf einem Raster ausgerechnet, nicht über ein Abstandsverhältnis geschätzt. Der Randstreifen von 0,5 m wird dabei nicht bewertet.
  • Wandabstand: Die größte Stellschraube für die Gleichmäßigkeit ist nicht die Leuchtenzahl, sondern der Abstand der Randleuchten zur Wand. S/3 statt S/2 kostet keine Leuchte und keine Energie.
  • Betriebswirkungsgrad: Der gerechnete Wert gilt für diffuse Reflexion und eine gleichmäßig belegte Leuchtenebene. Liegt die Wirkungsgradtabelle der Leuchte vor, stellen Sie auf aus dem Datenblatt um und tragen den Wert für Ihren Raumindex und Ihre Reflexionsgrade ein - der Hersteller kennt die Lichtverteilung seiner Leuchte, dieses Werkzeug nicht.
  • Berechnen: Klicken Sie auf den Button, um die Anzahl der Leuchten, das Raster und die erwarteten Lux zu berechnen.
  • 3D Ansicht: Nutzen Sie die Maus, um den Raum zu drehen (Linksklick) oder zu zoomen (Mausrad).

Berechnungsformeln

// Raumindex (Room Index K)
K = (L * W) / ((L + W) * Hm)

// Direktanteil: Formfaktor Leuchtenebene -> Nutzebene
DR = F(L/Hm, W/Hm)   // geschlossene Loesung nach Hottel

// Betriebswirkungsgrad aus der Strahlungsbilanz
// Decke, Waende und Nutzebene, diffuse Reflexion
UF = Lichtstrom auf der Nutzebene / Lichtstrom der Leuchten

// Benötigter Lichtstrom (Flux)
TotalFlux = (ZielLux * Fläche) / (UF * Wartungsfaktor)

// Anzahl Leuchten
N = TotalFlux / Lumen_pro_Leuchte

// Gleichmäßigkeit: Beleuchtungsstärke Punkt für Punkt
E = I0 * h² / (h² + r²)²,   I0 = Phi / pi   (Lambert-Strahler)
U0 = E_min / E_mittel   auf der Bewertungsfläche ohne 0,5 m Randstreifen
